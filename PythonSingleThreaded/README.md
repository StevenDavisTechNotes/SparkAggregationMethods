# Python Single-Threaded Aggregation Methods

> **Note**: This is a sub-project of the [Spark Aggregation Methods](../README.md) repository. Please refer to the parent repository for a full overview of the benchmarking project.

This directory contains the baseline implementations for the aggregation challenges using single-threaded Python (typically Pandas and NumPy). These implementations serve as the performance and correctness baselines for the distributed frameworks.
